# Оценка русского распознавания

Это протокол будущей оценки, не готовый benchmark runner.
Начать с 10–20 коротких фрагментов с разрешением на обработку:
чистая речь, шум, несколько голосов, имена/термины, тишина.
Добавить длинную запись для проверки повторов и потери контекста.

Аудио и эталоны хранить вне Git. Скопировать manifest.example.json в
manifest.local.json и указать локальные пути к фрагментам и эталонам.
Пример не содержит настоящих данных и не должен восприниматься как готовый набор.

Сравнивать модели на одинаковых фрагментах и параметрах:
WER/CER после явно описанной нормализации, время/длительность записи,
пиковая память, повторы и выдуманный текст на тишине.
Порог приемлемого качества и бюджета времени согласовать до замера.
Отдельно проверять правильность имён и терминов: средний WER их маскирует.

Карточка distil-large-v3 указывает английскую специализацию:
https://huggingface.co/distil-whisper/distil-large-v3
Для русского набора рассмотреть многоязычные medium и large-v3;
выбор не считается сделанным без измерений на данной машине.

Проверка сценария приложения на копии:
1. Один аудиофайл → одна заметка и один архивный оригинал с тем же SHA-256.
2. Ссылка открывает нужное аудио из Obsidian в целевой ОС.
3. Повторный запуск не создаёт дубликатов.
4. Коллизия имени не подменяет существующее аудио.
5. Сбой записи или недоступный Ollama не теряет источник.
6. --dry-run не меняет файловую систему.

Результаты сохранять в evals/results/ (исключено из Git).
Публиковать можно обезличенную сводку отдельно, после проверки содержимого.
