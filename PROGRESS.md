# Состояние проекта

Обновлено: 2026-11-03.

## Реализовано

- Проверка конфигурации и путей до обработки; поддержка `--config`, `--list` и `--dry-run`.
- Проектная документация, лёгкая проверка репозитория и критерии функций.
- Русская транскрипция через faster-whisper; метаданные людей сохраняют написание из распознанного текста.

## Профиль распознавания

- Whisper large-v3, русский язык, CPU float32.
- VAD выключен, фиксированный initial prompt не используется.
- WAV подготавливается как моно 16 кГц без дополнительного фильтра по умолчанию.
- Hotwords необязательны; для уже существующих заметок очередь может брать их из метаданных.
- Выбор сделан после сравнения на одной частной русской записи с ручной расшифровкой. Это не оценка качества на всём архиве. Личные аудио, заметки, эталоны и результаты остаются вне Git.

## Текущий этап

Планируется повторная обработка существующих заметок партиями по 20 по команде владельца. Первая партия запускается отдельно и хранит manifest, состояние, контрольные суммы, резервные копии и ошибки в игнорируемом каталоге `data/`. Обработка не должна автоматически переходить к следующей партии.

## Проверки и ограничения

`python scripts/check.py` проверяет структуру репозитория, а не качество ASR или безопасность массового запуска. Для оценки качества нужны русские эталонные тексты и сравнение ошибок на нескольких записях. Изменение модели и параметров на всём архиве ещё не завершено.
