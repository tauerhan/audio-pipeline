# План: основа репозитория

## Область
Сохранить шесть исходных скриптов, добавить документацию, зависимости,
пример конфига, инструкции агенту, CI и план развития.

## Проверка
- Python-файлы синтаксически корректны.
- Публичные YAML/JSON разбираются.
- Git исключает рабочий конфиг, ключи, данные, модели и окружение.
- SHA-256 исходных скриптов совпадает с первоначальной Ubuntu-копией.
- Лёгкая проверка проходит в текущем Python 3.10 окружении Ubuntu.
- Remote указывает на указанный владельцем tauerhan/audio-pipeline.

## За пределами этапа
Рефакторинг алгоритмов, исправление рабочего конфига, распознавание,
перенос оригиналов, изменение заметок, замеры моделей и web UI.

## Публикация
Первый коммит и push выполняются после поручения владельца и настройки
GitHub SSH-аутентификации. До этого репозиторий подготовлен, но не опубликован.
